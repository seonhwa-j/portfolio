# 정선화 포트폴리오

Vue 3, Vite, TypeScript, SCSS로 만든 웹퍼블리셔 포트폴리오입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`으로 확인합니다.

## 빌드

```bash
npm run build
```

Vercel 배포 시 기본 설정은 아래처럼 두면 됩니다.

```text
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
```
